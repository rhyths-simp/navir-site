designed for beginners

The thing that stopped you from using the terminal? Gone.

Most terminal tools assume you already know everything. navir assumes you know nothing — and that's completely fine. You'll be navigating files in under a minute.

🗑️

"What if I delete something important?"

Every deletion in navir goes to a safe recycle bin — zipped and timestamped, never permanently gone. Ctrl+D is the safest delete button you've ever pressed.

⌨️

"I'll never remember all these shortcuts."

You don't have to. Start with five keys: arrows to move, Enter to open, Esc to go back, / to search, Q to quit. Everything else reveals itself as you need it.

⚡

"Setup sounds complicated."

One curl command. That's the entire installation. No dependencies to install, no configuration files to edit, no Python packages to manage. It just works.

how it works

Up and running in three steps.

No tutorials. No documentation to study. Just install, open, and start navigating.

STEP 01  —  INSTALL
curl -fsSL .../install.sh | bash

One command sets everything up.

Paste the install command into your terminal and press Enter. navir clones itself, creates the navir command, and sets up your personal plugin folder — in seconds.

STEP 02  —  LAUNCH
navir

Type navir. That's it.

Your files appear instantly. Use the arrow keys or W/S to move up and down. Press Enter to open a folder or file. Press Esc to go back. You already know how to use it.

STEP 03  —  EXPLORE
Ctrl+T

Discover more when you're ready.

Press Ctrl+T at any time to see a full menu of every available action. Copy, move, rename, search, preview — it's all there, discoverable, with no memorization required.

the safety net

Delete anything.
Regret nothing.

When you press Ctrl+D in navir, your file doesn't disappear. It gets zipped into a timestamped archive and stored safely in your recycle bin. The original filename, folder structure, and every byte of data — preserved.

Accidentally deleted a whole project folder? No problem. It's sitting in ~/recycle_bin/ as a zip archive, exactly as it was.

restore

To recover anything: cd ~/recycle_bin then unzip filename.zip. Your files are back exactly as they were.

plugin system

Extend when you're ready.
Never required to.

navir ships with three built-in plugins for git, bookmarks, and file preview. When you outgrow those, writing your own is as simple as dropping a Python file in a folder — no build step, no restart.

Ctrl+G
git_plugin
Live git status for the current folder. Branch name, modified files, untracked changes.
Ctrl+B
bookmarks_plugin
Save your most-visited folders and jump to them instantly. Persists across sessions.
Ctrl+P
preview_plugin
Peek inside any file without opening it. Shows text content, image dimensions, MIME types.
Writing your own plugin? Drop a .py file into ~/.navigator/plugins/ and it loads automatically on next start. Plugin errors are logged silently — a broken plugin can never crash the app.
my_plugin.pyPython
# Drop into ~/.navigator/plugins/ # Loads on next navir start. That's it. NAME = "my_plugin" VERSION = "1.0" DESCRIPTION = "Does something useful" def register(api): api.add_keybind( "Ctrl+E", "My Action", on_ctrl_e ) def on_ctrl_e(api, path, item): api.show_status( f"Working on {item}!" )
